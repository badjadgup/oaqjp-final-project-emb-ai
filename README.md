# Final Project

Emotion Detection application for Developing AI Applications with Python and Flask.
Uses Watson NLP to report anger, disgust, fear, joy, sadness, and the dominant emotion.

## Run in the Skills Network lab

```bash
cd /home/project/final_project
python3 -m pip install -r requirements.txt
python3 test_emotion_detection.py
python3 server.py
```

Open the lab's application preview on port 5000. The Watson endpoint may require
the course lab environment. This application does not substitute fake scores
when the service is unavailable.
